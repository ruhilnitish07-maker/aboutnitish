# aboutnitish

Source code for my personal links and portfolio page: **[aboutnitish.netlify.app](https://aboutnitish.netlify.app)**

A single-page site (HTML, CSS and vanilla JavaScript, no build step) with my links, projects, experience and certificate. It supports light and dark mode and has scroll animations.

## What's on the page

- Links to my E-Portfolio, Student Communication Toolkit, Duffeldrops, Campus Hide & Seek, UPI Spend Tracker, LinkedIn and GitHub
- Project cards, experience and education
- SmartED Campus Ambassador certificate

## Project structure

```
aboutnitish/
├── index.html        The whole site (styles, markup and script in one file)
└── certificate.jpg   Certificate image shown on the page (add this file to the repo)
```

## Edit the content

All text and links live in the `CONFIG` object near the bottom of `index.html`. Change the values there and the page updates itself.

## Run locally

Open `index.html` in a browser. No installation is needed.
